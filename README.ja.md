# Mail Archive

XeFM 用の拡張機能です。`.eml` と Outlook の `.msg` メールを、本文・ヘッダー・添付ファイルを閲覧できる**読み取り専用の仮想フォルダー**として開きます。元のメールファイルを書き換えず、XeFM の通常のファイル一覧と同じように中身を確認できます。

- 対応形式: `.eml`、`.msg`
- 拡張機能 ID: `mail-archive`
- バージョン: `0.1.3`
- XeFM の最低対応バージョン: `1.10.0`
- `.eml` の解析には Python 標準ライブラリを使用します。
- `.msg` の読み込みには `extract-msg` が必要です。拡張機能の依存パッケージとして宣言されており、XeFM の Python パッケージ同期で導入します。

## インストール

XeFM を使っている環境で、次のコマンドを実行します。

```text
xefm ext install github:SinisterSoftware/xefm-mail-archive
```

インストール時に追加内容や依存パッケージの同期を確認された場合は、表示内容を確認して許可してください。依存パッケージを後から同期する場合は、次のいずれかを実行します。

```text
xefm deps sync
```

または XeFM の **Tools > Advanced > Sync Python Packages** を選びます。拡張機能が読み込まれていることは `xefm ext list` で確認できます。

## メールを開く

XeFM のファイル一覧で `.eml` または `.msg` を選び、コマンドパレットから `mail_archive.open` アクションを実行すると、対応する仮想フォルダーとして開きます。この拡張機能は `file_open` フックを登録しません。外部ビューアーで開かなかったメールをこのアクションに渡す external-viewer 拡張機能と併用すると、**Enter** でも開けます。

すでに仮想フォルダーを開いている場合や、パスを直接入力したい場合は、XeFM の **Jump to Path** アクションを使って次の形式のパスへ移動します。

```text
eml://C:\path\to\message.eml#
msg://C:\path\to\message.msg#
```

`#` の後ろが仮想フォルダー内のパスです。たとえば `eml://C:\mail\message.eml#header.txt` は、そのメールのヘッダーを指します。OS-native キーマップでは **Ctrl+L**、AFX キーマップでは **Shift+J**、Vim キーマップでは **g p** が Jump to Path の既定キーです。キーマップやユーザー設定によって異なる場合は、XeFM のコマンドパレットから **Jump to Path** を検索してください。

## 仮想フォルダーの中身

### `.eml`

ルートには、メールに含まれるヘッダーを UTF-8 で出力した `header.txt` と、ファイル名のない本文パートがあれば `message000(文字コード名).txt` または `.html` の形式で表示されます。複数の本文パートは連番になります。添付ファイルやファイル名のないインラインパートがある場合は `attach` フォルダーにまとめられます。

### `.msg`

ルートには `message.txt` が表示され、差出人、宛先、Cc、日付、件名、添付ファイル名の一覧、本文をまとめて確認できます。Bcc は値がある場合に表示されます。添付ファイルがある場合は `attach` フォルダーにも個別のファイルとして表示されます。

### 添付ファイル

`attach` を開くと添付を仮想ファイルとして一覧できます。添付名が重複する場合は `_2` などの連番が付加されます。`.eml` のファイル名のないインラインパート（画像など）は `partNNN.拡張子` の形式になります。

添付を通常のファイルとして保存するには、片方のペインで保存先フォルダーを開き、もう片方で `attach` を開いて保存したいファイルを選び、XeFM の通常のファイルコピー操作を実行します。OS-native / Vim キーマップでは既定で **F5**、AFX キーマップでは対象を選択して **C** です。キーは設定によって異なる場合があります。コピーされたファイルは保存先に作られ、仮想フォルダーや元のメールは変更されません。

仮想フォルダー内のファイルは読み取り専用です。添付を直接編集・上書きする場所ではありません。コピーして保存したファイルを変更する場合は、対応するアプリケーションを使用してください。

## ファイルを開くアクション

`mail_archive.open` はコマンドパレットでアクション名を検索して実行できます。このアクションは、現在フォーカスされている `.eml` / `.msg` ファイルだけを開きます。フォルダー、親項目、別形式のファイル、空の一覧では何も開きません。

XeFM の標準キーマップでは、コマンドパレットの既定キーは OS-native で **Ctrl+K**、AFX で **Ctrl+T**、Vim で **:** または **Ctrl+T** です。設定済みのキーが異なる場合は、コマンドパレットのアクション一覧から確認してください。

ほかの XeFM 拡張機能からこのアクションを呼び出す場合は、アクションの存在を確認してから実行できます。

```python
if "mail_archive.open" in ctx.action_names():
    ctx.invoke("mail_archive.open")
```

アクションはフォーカス中のメールファイルだけを対象にします。

## 制限と補足

- メールと仮想フォルダーの内容は読み取り専用です。元のメールファイルを更新する用途には使えません。
- `.msg` を開けない場合は `extract-msg` が未導入の可能性があります。上記の Python パッケージ同期を実行してください。
- `.eml` の本文は MIME パート単位で表示します。本文パートのファイル名が指定されている場合は添付として扱われ、`attach` 側に表示されます。
- `.msg` の HTML 本文はテキスト表示用に簡易変換されます。スクリプトとスタイル要素を除去し、主要な改行タグを改行に変換してタグを取り除きます。ブラウザーと同じ見た目での HTML レンダリングではありません。
- 同じメールファイルを再表示する内容はファイルの更新日時を基準にキャッシュされます。

## トラブルシューティング

**Enter でメールが外部アプリに開かれる、または仮想フォルダーにならない**

`xefm ext list` で `mail-archive` が読み込まれているか確認し、コマンドパレットから `mail_archive.open` を実行して開けるか確認してください。Enter で開くには、external-viewer 側が外部ビューアーで開かなかったメールをこのアクションに渡す必要があります。

**`.msg` を開くと依存パッケージのエラーになる**

`xefm deps sync`、または **Tools > Advanced > Sync Python Packages** を実行し、同期が完了してから再度開いてください。

**仮想フォルダーのファイルが見つからない**

ルートにはメールに実際に含まれるヘッダー・本文パートだけが表示されます。`attach` フォルダーは添付やファイル名のないインラインパートがある場合に表示されます。`.msg` では本文と添付一覧が `message.txt` に記載されます。
